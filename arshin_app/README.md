## 📖 ОПИСАНИЕ

GUI-приложение на Tkinter для поиска, сбора и экспорта данных из ФГИС АРШИН.

**Назначение:**
- 🔍 Поиск по реестру поверок средств измерений
- 📦 Пакетная обработка запросов из Excel
- 📊 Экспорт результатов с полной служебной информацией

> Для консольной/серверной работы используйте **Konsol_Excel** (`../Konsol_Excel/`) — поддерживает SSH, tmux, cron, параллельные запросы, возобновление после сбоя.

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка зависимостей

```bash
cd arshin_app

# Активация виртуального окружения (из корня проекта)
source ../venv/bin/activate    # Linux
# или
..\venv\Scripts\activate       # Windows

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск

```bash
./run.sh                        # Linux
bash run.sh                     # Linux (если нет +x)
run.bat                         # Windows
# или напрямую:
python arshin_app.py
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **API лимиты:** API ФГИС АРШИН имеет ограничения на количество запросов (429 Too Many Requests)
2. **Фильтрация:** Автоматически фильтруются только электросчетчики (~15% от всех записей)
3. **URL записей:** Генерируется из `vri_id`: `https://fgis.gost.ru/fundmetrology/cm/erts/?id={vri_id}`
4. **Логи:** Логи консольной версии в `../Konsol_Excel/Logs/`

## 📞 ПОДДЕРЖКА

При возникновении проблем:

1. Проверьте логи в `../Konsol_Excel/Logs/` (консоль)
2. Проверьте доступность API: `curl https://fgis.gost.ru/fundmetrology/eapi/vri`
3. Изучите документацию в `../Docs/` и `../Konsol_Excel/`
