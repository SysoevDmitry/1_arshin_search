## 📖 ОПИСАНИЕ

Приложение для поиска, сбора и экспорта данных из федеральной государственной информационной системы "Аршин" (ФГИС АРШИН).

**Назначение:**
- 🔍 Поиск по реестру поверок средств измерений
- 📦 Пакетная обработка запросов из Excel
- 📊 Экспорт результатов с полной служебной информацией
- 🚀 Консольная версия для удалённых серверов

---

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка зависимостей

```bash
# Перейдите в директорию проекта
cd 1_arshin_search

# Активация виртуального окружения
# Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск GUI версии

```bash
python arshin_app.py
```

### 3. Запуск консольной версии (Konsol_Excel)

```bash
# Через скрипт запуска (рекомендуется)
# Linux:
./Konsol_Excel/run.sh --stats
# Windows:
Konsol_Excel\run.bat --stats

# Пакетный поиск
./Konsol_Excel/run.sh -f запросы.xlsx -y 2020-2025 -o результат.csv

# Помощь
python Konsol_Excel/main.py --help
```

## ✨ ВОЗМОЖНОСТИ

### GUI версия (`arshin_app.py`)

| Вкладка | Описание |
|---------|----------|
| 🔍 Поиск | Одиночный поиск по реестру |
| 📦 Пакетная | Пакетный поиск из Excel файла |
| 📋 Результаты | Просмотр, фильтрация, экспорт БД |
| 🔧 Фильтры | Управление конфигурацией |
| 📊 Статистика | Статистика по базе данных |

**Функции:**
- ✅ Автоматическое определение колонок Excel
- ✅ Фильтрация (только электросчетчики)
- ✅ Экспорт в CSV/Excel с русскими заголовками
- ✅ Сохранение служебной информации (Id_ПУ, Номер договора, Код ЭДО и т.д.)
- ✅ 20 колонок в таблице результатов

### Консольная версия (`arshin_app_konsol.py`)

**Параметры:**
```bash
python arshin_app_konsol.py -f файл.xlsx -y 2020,2021,2022 -o результат.csv
python arshin_app_konsol.py --stats      # Статистика БД
python arshin_app_konsol.py --clear      # Очистить БД
```

**Преимущества:**
- ✅ Работа через SSH/терминал
- ✅ Не требует GUI/X11
- ✅ Поддержка tmux/screen для фоновой работы
- ✅ Автоматизация через cron

## 🔧 КОНФИГУРАЦИЯ

### Файл `config/exact_queries.csv`

Точные запросы для приоритетного поиска:

```csv
query,category,priority
Счетчик электрической энергии Меркурий 201,electric,high
Счетчик электрической энергии Нева 103,electric,high
```

Словарь производителей:

```csv
keyword,manufacturer,category,priority
меркурий,Меркурий,electric,high
нева,Нева,electric,high
энергомера,Энергомера,electric,high
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **API лимиты:** API ФГИС АРШИН имеет ограничения на количество запросов
2. **Фильтрация:** Автоматически фильтруются только электросчетчики (~15% от всех записей)
3. **URL записей:** Генерируется из `vri_id`: `https://fgis.gost.ru/fundmetrology/cm/erts/?id={vri_id}`
4. **Миграция БД:** Не требуется, база пересоздаётся автоматически
