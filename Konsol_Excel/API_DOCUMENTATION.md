## 1. Введение

### 1.1 Область применения

Компонент **«Внешние публичные интерфейсы»** предназначен для предоставления в автоматическом режиме сведений, содержащихся в следующих разделах **Федерального информационного фонда по обеспечению единства измерений (ФИФ ОЕИ)**:

| № | Реестр / Перечень |
|---|-------------------|
| 1 | Реестр государственных первичных эталонов |
| 2 | Реестр эталонов единиц величин |
| 3 | Реестр утвержденных типов СИ |
| 4 | Реестр утвержденных типов стандартных образцов (СО) |
| 5 | Перечень СИ, применяемых в качестве эталонов |
| 6 | Перечень веществ (материалов), используемых при поверке |
| 7 | Реестр сведений о результатах поверки СИ |

**Назначение:** Интеграция информационных систем организаций-поверителей с подсистемой **«АРШИН»** ФГИС Росстандарта для поиска и получения данных о поверке средств измерений.

---

### 1.2 Уровень подготовки пользователя

Данное руководство рассчитано на **продвинутых пользователей**:
- 👨‍💻 Разработчиков программного обеспечения
- 🔧 Инженеров по качеству
- 🧪 Тестировщиков (QA)

**Технологии:**
- Протокол **HTTP 1.1**
- Архитектурный стиль **REST**
- Формат данных **JSON**

## 3.1 Получение списка элементов реестра

### 📍 Адреса запросов

| URL | Раздел ФИФ ОЕИ |
|-----|---------------|
| `mit` | Реестр утвержденных типов СИ |
| `npe` | Реестр государственных первичных эталонов |
| `uve` | Реестр эталонов единиц величин |
| `set` | Реестр утвержденных типов СО |
| `mieta` | Перечень СИ, применяемых в качестве эталонов |
| `rgnt` | Перечень веществ (материалов), используемых при поверке |
| `vri` | Реестр сведений о результатах поверки СИ |

**Пример:**
```bash
GET https://fgis.gost.ru/fundmetrology/eapi/mit
```

---

### 3.1.1 Параметры запроса

#### Основные параметры

| Параметр | Описание | По умолчанию | Ограничения |
|----------|----------|--------------|-------------|
| `search` | Подстрока поиска с подстановочными символами `*` и `?` | `*` | — |
| `sort` | Атрибут и порядок сортировки (например, `number+desc`) | `number+desc` | — |
| `start` | Порядковый номер начальной записи | `0` | ≤ 99 999 |
| `rows` | Количество элементов на страницу | `10` | ≤ 100 |
| `<атрибут>` | Фильтр по атрибуту (см. раздел 3.3) | — | — |

#### Синтаксис поиска (параметр `search`)

| Тип поиска | Синтаксис | Пример |
|------------|-----------|--------|
| По началу строки | `строка*` | `search=тестер*` |
| Подстрока | `*строка*` | `search=*тестер*` |
| Несколько подстрок (AND) | `строка1*строка2*строка3` | `search=тестер*цифровой*` |
| Значение с пробелом | `до?после` | `search=до?пробела` |
| Поиск `*` или `?` | Как для пробела | `search=знак?вопроса` |

#### Дополнительные параметры для реестра поверок (vri)

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `year` | Год поверки | Текущий год (если не указан `verification_date`) |
| `verification_date` | Конкретная дата поверки (yyyy-MM-dd) | — |

> ⚠️ **Важно:** Если указан `verification_date`, параметр `year` не применяется.

#### Примеры запросов

```bash
# Список из 20 утвержденных типов СИ, начиная с 5-го элемента
GET https://fgis.gost.ru/fundmetrology/eapi/mit?start=5&rows=20

# Поиск по подстроке с сортировкой
GET https://fgis.gost.ru/fundmetrology/eapi/mit?search=*тестер*&sort=number+desc

# Атрибутивный поиск (рекомендуется!)
GET https://fgis.gost.ru/fundmetrology/eapi/mit?mit_number=38760-08&mi_number=0810956509

# Поверки текущего года
GET https://fgis.gost.ru/fundmetrology/eapi/vri

# Поверки за 2021 год
GET https://fgis.gost.ru/fundmetrology/eapi/vri?year=2021

# Поверки на конкретную дату
GET https://fgis.gost.ru/fundmetrology/eapi/vri?verification_date=2021-09-01
```

---

### 3.1.2 Ответ на запрос

#### ✅ Успешный ответ (200 OK)

```json
{
  "result": {
    "count": 102816,
    "start": 0,
    "rows": 2,
    "items": [
      {
        "mit_id": "7",
        "number": "77963-20",
        "title": "Термопреобразователи прецизионные",
        ...
      }
    ]
  }
}
```

| Атрибут | Описание | Тип |
|---------|----------|-----|
| `result.count` | Количество найденных элементов | Целое число |
| `result.start` | Номер начальной записи в выборке | Целое число |
| `result.rows` | Количество строк на странице | Целое число |
| `result.items` | Массив найденных элементов | Массив объектов |

#### 📭 Пустой результат

```json
{
  "result": {
    "count": 0,
    "start": 0,
    "rows": 10,
    "items": []
  }
}
```

#### ❌ Ошибка (4xx / 5xx)

```json
{
  "status": "BAD_REQUEST",
  "message": "Параметр owner не допустим для запроса",
  "time": "2022-09-14T18:43:04.305+03:00",
  "requestId": "29d02b7d-cea3-4d13-8caf-53d8c612f65f"
}
```

| Атрибут | Описание | Тип |
|---------|----------|-----|
| `status` | Код ошибки | Строка |
| `message` | Описание причины ошибки | Строка |
| `time` | Время возникновения ошибки | Дата и время |
| `requestId` | Уникальный идентификатор запроса | UUID |

#### 🚫 Типовые ошибки

| Код | Описание | Решение |
|-----|----------|---------|
| **429** | Too Many Requests | Пауза между запросами (≤ 2 запросов/сек) |
| **408** | Request Timeout | Использовать атрибутивный поиск |
| **400** | Bad Request | Проверить параметры запроса |
| **404** | Not Found | Элемент не найден |
| **5XX** | Ошибка сервера | Обратиться в поддержку |

> 📧 **При ошибках 5XX:**  
> Обратитесь в Службу сопровождения: **fgis2@rst.gov.ru**  
> Приложите: ответ с ошибкой, запрос и время отправки с указанием часового пояса.

## 3.2 Получение элемента реестра

### Запрос

```bash
GET {АдресДляПолученияСписка}/{ИдентификаторВерсииЭлемента}
```

**Пример:**
```bash
GET https://fgis.gost.ru/fundmetrology/eapi/mit/fee2ff47-70d8-4165-f1ee-e508987d7381
```

> ℹ️ Идентификатор версии элемента (`*_uuid` / `*_id`) можно получить из списка элементов (раздел 3.1).  
> При изменении сведений создаётся новая версия элемента с новым идентификатором.

### 3.2.1 Ответ на запрос

| Статус | Описание |
|--------|----------|
| **200 OK** | Успешный ответ, тело в формате JSON (схема – раздел 3.3) |
| **404 Not Found** | Элемент не найден |
| **4xx / 5xx** | Ошибка (формат как в разделе 3.1.2) |

## 4. Рекомендации по использованию

### ✅ Используйте атрибутивный поиск вместо `search`

| Преимущество | Описание |
|--------------|----------|
| 🎯 Точность | Поиск только в нужных атрибутах |
| ⚡ Скорость | Более высокая скорость обработки |
| 🔤 Пробелы | Возможность поиска значений с пробелами без дополнительной проверки |

**Пример:**
```bash
# ❌ Не рекомендуется (медленно)
GET /eapi/vri?search=12345678

# ✅ Рекомендуется (быстро)
GET /eapi/vri?mi_number=12345678
```

---

### 🚨 При ошибке 408 Request Timeout

| Шаг | Действие |
|-----|----------|
| 1 | Замените `search` на атрибутивный поиск |
| 2 | Используйте `*` только в начале или конце строки |
| 3 | Увеличьте количество фиксированных символов |
| 4 | При сохранении ошибки – исключите подстановочные символы |

---

### ⚖️ Балансировка нагрузки

> При выполнении одинаковых запросов к недавно изменённым данным возможны расхождения в результатах до полной синхронизации сервисов.

---

### 📋 Статус записи `publication.status`

> Если `publication.status = "Запись была модифицирована"` – возвращённые сведения неактуальны.  
> **Решение:** Выполните повторный поиск.

---

### 📅 Поиск результатов поверки без указания дат

> Без параметра `year` или `verification_date` возвращаются сведения **только за текущий год**.

---

### 📐 Обозначение степеней в тексте

> Значения вида `кгс/см[^2]` соответствуют **кгс/см²**.

## 📎 Приложения

### A. Быстрый старт

```bash
# 1. Поиск по реестру утвержденных типов СИ
curl "https://fgis.gost.ru/fundmetrology/eapi/mit?rows=10"

# 2. Атрибутивный поиск по серийному номеру
curl "https://fgis.gost.ru/fundmetrology/eapi/vri?mi_number=123*&year=2024"

# 3. Получение записи по ID
curl "https://fgis.gost.ru/fundmetrology/eapi/vri/2-162158132"

# 4. Поиск по конкретной дате
curl "https://fgis.gost.ru/fundmetrology/eapi/vri?verification_date=2024-03-04"
```
