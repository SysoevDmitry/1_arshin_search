# CHANGELOG v6.4 — Авто-диапазон

## 2026-06-19 — Авто-диапазон и цепочка приоритетов

### `--auto-range` — авто-диапазон для каждой строки
- Флаг `--auto-range` включает режим, при котором для каждой строки Excel определяется **свой** диапазон поиска
- Диапазон: `год − 1 … год + 2` (4 года)
- Без флага — старый режим с глобальным `-y` (по умолчанию 2020–2025)

### Цепочка приоритетов
Для каждой строки применяется первый доступный источник года:

| Приоритет | Колонка | Уровень |
|-----------|---------|---------|
| 1 | **Дата поверки. Год** | Строка |
| 2 | **Год выпуска** | Строка |
| 3 | Мода **Дата госповерки** (наиболее частое значение по файлу) | Файл |
| 4 | Последние 7 лет от текущей даты | Глобально |

### Новые колонки Excel
- `verification_year` — «Дата поверки. Год» (год из столбца «Дата поверки. Год»)
- `gosverka_date` — «Дата госповерки» (полная дата, извлекается год через `\d{4}`)

### Изменённые файлы
- `excel_handler.py` — детектирование колонок `verification_year` и `gosverka_date`
- `collector.py` — `_adjust_years_for_query` с цепочкой приоритетов, `_extract_year_from_date`, `_compute_base_year_from_gosverka`, обновлён `process_queries_batch`
- `main.py` — флаг `--auto-range`, вычисление базового года, обновлён `parse_years`

### Логирование
- Диапазон для каждой строки выводится в лог на уровне **INFO** (ранее DEBUG)
- В консоли отображается режим и цепочка приоритетов

### Обратная совместимость
- Без `--auto-range` поведение полностью идентично v6.3
- `-y` по умолчанию `2020-2025` (как и было)
