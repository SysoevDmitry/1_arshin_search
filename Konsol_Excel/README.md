# ФГИС АРШИН - Excel версия v6.1

## 🎯 Назначение

Пакетная обработка Excel файлов с запросами к ФГИС АРШИН с **полной функциональностью arshin_app.py**:

- ✅ Параллельные запросы к API
- ✅ Сохранение связей (Id_ПУ, № строки, данные из файла)
- ✅ Проверка на **ПОЛНУЮ уникальность** (как в arshin_app.py)
- ✅ Автоматическое определение колонок Excel
- ✅ Экспорт с русскими заголовками и всеми служебными полями

## 🔑 Ключевые особенности

### 1. Проверка на ПОЛНУЮ уникальность

Адаптировано из `arshin_app.py` - проверка по **13 полям**:

```python
def get_unique_key(self) -> tuple:
    return (
        self.vri_id,
        self.mit_number,
        self.mit_title,
        self.mi_number,
        self.verification_date,
        self.valid_date,
        self.applicability,
        self.org_title,
        self.result_docnum,
        self.manufacturer,
        self.search_query,
        self.row_index,
        self.id_pu
    )
```

**Преимущество:** Одна и та же запись может быть сохранена несколько раз для разных строк Excel (разные Id_ПУ, договоры и т.д.)

## 🗄️ Структура базы данных

### Таблица `verification_records`

**Основные поля (из API):**
- `vri_id` - Уникальный ID записи
- `mit_number` - Номер в реестре типов СИ
- `mit_title` - Наименование типа СИ
- `mi_number` - Заводской номер
- `verification_date` - Дата поверки
- `valid_date` - Действительна до
- `applicability` - Пригодность
- `org_title` - Поверитель
- `result_docnum` - Номер документа

**Служебные поля:**
- `manufacturer` - Производитель (определяется автоматически)
- `collected_at` - Время сохранения

**Поля связей (из Excel):**
- `search_query` - Поисковый запрос
- `row_index` - № строки в Excel (1-based)
- `id_pu` - Id_ПУ из файла

**Данные из файла:**
- `contract_number` - Номер договора
- `edo_code` - Код ЭДО
- `balance_owner` - Балансовая принадлежность
- `operation_responsibility` - Эксплуатационная ответственность
- `mpi` - МПИ

## 🐛 Решение проблем

### Много дублей
Это нормально! Проверка на полную уникальность позволяет сохранять одну запись API для разных строк Excel (разные Id_ПУ, договоры).

### Ошибки 429 (Too Many Requests)
```bash
# Уменьшить параллелизм
python main.py -f запрос.xlsx -y 2020-2025 --concurrent 3
```

### Ошибки 408 (Request Timeout)
Автоматически выполняется повторная попытка (до 3 раз).

### Не определяются колонки
Проверьте названия колонок в Excel. Поддерживаются:
- 'серийный номер', 'заводской номер', 'номер пу', 'id_пу'
- 'номер договора', 'код эдо', 'мпи', и т.д.
