# ФГИС АРШИН - Excel версия v6.2

## 🎯 Назначение

Пакетная обработка Excel файлов с запросами к ФГИС АРШИН:

- ✅ Параллельные запросы к API (до 10 одновременных)
- ✅ Атрибутивный поиск (mi_number=, mit_number=)
- ✅ Сохранение ведущих нулей в серийных номерах
- ✅ Сохранение связей (Id_ПУ, № строки, данные из файла)
- ✅ Проверка на **ПОЛНУЮ уникальность** (14 полей)
- ✅ Автоматическое определение колонок Excel (алгоритм наилучшего совпадения)
- ✅ Учёт года выпуска прибора (поиск от года выпуска)
- ✅ Запрос очистки/добавления перед поиском
- ✅ Автосохранение результатов в `exports/`
- ✅ Логи в `Logs/`
- ✅ Экспорт с русскими заголовками

## 📊 Структура Excel файла

| Колонка | Описание | Пример |
|---------|----------|--------|
| Заводской номер | Серийный номер прибора | `023241147596` |
| Наименование | Тип прибора | `Счетчик электрической энергии...` |
| Номер в реестре | Номер в реестре СИ | `77310-20` |
| Id_ПУ | Идентификатор точки учёта | `ПУ-001` |
| **Год выпуска** | Год выпуска прибора | `2023` |
| Номер договора | Договор с поставщиком | `Д-001/2023` |
| Код ЭДО | Код электронного документооборота | `123456789` |
| МПИ | Межповерочный интервал | `16` |

Если указан **Год выпуска** — поиск для этой строки идёт от года выпуска до конца диапазона.

## 🔑 Ключевые особенности

### 1. Проверка на полную уникальность (14 полей)

```python
(vri_id, mit_number, mit_title, mi_number, verification_date,
 valid_date, applicability, org_title, result_docnum, sticker_num,
 manufacturer, search_query, row_index, id_pu)
```

### 2. Ведущие нули в серийных номерах

Все колонки читаются как текст (`dtype=str`) — номера вида `023241147596` сохраняются без потерь.

### 3. Год выпуска прибора

Колонка «Год выпуска» сужает диапазон поиска для конкретной строки:  
`-y 2015-2026` + год выпуска `2023` → поиск `2023-2026`.

## 📤 Экспорт

Результаты автосохраняются в `exports/`. Если файл существует — добавляется дата и номер:

```
результат.csv → exports/результат.csv
результат.csv → exports/20260429_результат.csv (если существует)
20260429_результат.csv → exports/20260429_результат_1.csv
```

## 🐛 Решение проблем

### Ошибки 429 (Too Many Requests)
```bash
python main.py -f запрос.xlsx -y 2020-2025 --concurrent 3
```

### Не определяются колонки
Проверьте названия заголовков. Поддерживаются: «Заводской номер», «Серийный номер», «Id_ПУ», «Год выпуска» и т.д.

### Пустые логи
Логи пишутся в `Logs/arshin_excel_*.log`. Если файл пустой — очистите `__pycache__/`.
