# Конфигурационные файлы

В этой папке находятся файлы конфигурации для VRInfo.

## exact_queries.csv

Файл содержит точные запросы для приоритетного поиска электрических счетчиков.

**Формат:**
```csv
query,category,priority
Счетчик электрической энергии Меркурий 201,electric,high
```

**Поля:**
- `query` - Текст поискового запроса
- `category` - Категория (electric, gas, water, other)
- `priority` - Приоритет (high, medium, low)

## manufacturers.csv

Словарь ключевых слов для определения производителей.

**Формат:**
```csv
keyword,manufacturer,category,priority
меркурий,Меркурий,electric,high
```

**Поля:**
- `keyword` - Ключевое слово для поиска (в нижнем регистре)
- `manufacturer` - Название производителя для отображения
- `category` - Категория оборудования
- `priority` - Приоритет определения

## Добавление новых запросов

1. Откройте `exact_queries.csv` в текстовом редакторе
2. Добавьте новую строку в формате: `запрос,категория,приоритет`
3. Сохраните файл
4. Перезапустите приложение

## Добавление новых производителей

1. Откройте `manufacturers.csv` в текстовом редакторе
2. Добавьте новую строку: `ключевое_слово,Название,категория,приоритет`
3. Сохраните файл
4. Перезапустите приложение

**Важно:** Ключевые слова должны быть в нижнем регистре!
