# 🖥 Консольная версия ФГИС АРШИН

## 📋 Описание

`arshin_app_konsol.py` - консольная версия приложения для пакетной обработки на удалённых серверах без GUI.

**Преимущества:**
- ✅ Работает через SSH/терминал
- ✅ Не требует X11/GUI
- ✅ Минимальные требования к ресурсам
- ✅ Поддержка фоновой работы (tmux/screen)
- ✅ Полная поддержка всех функций пакетного поиска

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd /home/dmitry/Документы/АРШИН/Интерфейс/1_arshin_search

# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install pandas openpyxl aiohttp requests tqdm
```

### 2. Запуск

```bash
# Базовый запуск
python arshin_app_konsol.py -f тесты/Тестовый_запрос_2.xlsx -y 2020,2021,2022

# С экспортом в CSV
python arshin_app_konsol.py -f запросы.xlsx -y 2020-2025 -o результат.csv

# Показать статистику БД
python arshin_app_konsol.py --stats

# Очистить базу данных
python arshin_app_konsol.py --clear
```

---

## 📖 Параметры командной строки

| Параметр | Описание | Пример |
|----------|----------|--------|
| `-f, --file` | Excel файл с запросами | `-f запросы.xlsx` |
| `-y, --years` | Годы поиска | `-y 2020,2021,2022` или `-y 2020-2025` |
| `-o, --output` | Файл для экспорта CSV | `-o результат.csv` |
| `--stats` | Показать статистику БД | `--stats` |
| `--clear` | Очистить базу данных | `--clear` |
| `-v, --verbose` | Подробный режим | `-v` |

## 🗂 Формат входного файла

| Колонка | Обязательная | Описание |

| `Id_ПУ` | ❌ | Идентификатор прибора |
| `Модель` | ❌ | Наименование модели |
| `Тип ПУ` | ❌ | Тип прибора учёта |

| `Код ЭДО` | ❌ | Для экспорта |

| `Эксплуатационная ответственность` | ❌ | Для экспорта |

## ⚠️ Решение проблем

### Ошибка: "pandas не установлен"
```bash
pip install pandas
```

### Ошибка: "tqdm не установлен"
```bash
pip install tqdm
```

### Ошибка: "No module named 'aiohttp'"
```bash
pip install aiohttp
```

### Таймауты API
Увеличьте задержку в коде:
```python
Config.RETRY_DELAY = 5  # вместо 2 секунд
```

### Мало результатов
Проверьте:
1. Правильность серийных номеров в файле
2. Выбранные годы поиска
3. Фильтр "только электросчетчики"

## 🎯 Сценарии использования

### Сценарий 1: Регулярный поиск

```bash
#!/bin/bash
# daily_search.sh

DATE=$(date +%Y-%m-%d)
LOG_FILE="logs/search_${DATE}.log"

cd /home/dmitry/Документы/АРШИН/Интерфейс/1_arshin_search
source venv/bin/activate

python arshin_app_konsol.py \
    -f новые_запросы.xlsx \
    -y 2025,2026 \
    -o "exports/search_${DATE}.csv" \
    2>&1 | tee "$LOG_FILE"
```

### Сценарий 2: Массовый поиск за все годы

```bash
#!/bin/bash
# full_search.sh

cd /home/dmitry/Документы/АРШИН/Интерфейс/1_arshin_search
source venv/bin/activate

python arshin_app_konsol.py \
    -f полный_список.xlsx \
    -y 2010-2026 \
    -o exports/full_search.csv
```

### Сценарий 3: Автоматизация через cron

```bash
# Запуск каждый день в 02:00
0 2 * * * /home/dmitry/Документы/АРШИН/Интерфейс/1_arshin_search/daily_search.sh
```
