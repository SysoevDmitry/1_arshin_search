## О ПРОГРАММЕ

**ФГИС АРШИН** — приложение для работы с реестром поверок средств измерений через API ФГИС Аршин.

**Версия:** 2.13
**Платформа:** Linux/Windows
**Требования:** Python 3.9+, tkinter, pandas, openpyxl

---

## ВОЗМОЖНОСТИ

### 🔍 Одиночный поиск
- Поиск по заводскому номеру прибора
- Выбор годов поиска (2010-2026)
- Получение до 500 записей
- Сохранение в CSV или добавление в БД

### 📦 Пакетный поиск
- Загрузка Excel файла со списком приборов
- Автоматическое определение колонок
- Поиск по всем годам одновременно
- Фильтрация (только электросчетчики)

### 📋 Результаты
- Просмотр всех записей из БД
- Фильтрация по году и производителю
- Выделение и удаление записей
- Экспорт в CSV/Excel

### 🔧 Фильтры
- Управление точными запросами
- Управление производителями
- Загрузка/сохранение конфигурации

### 📊 Статистика
- Общее количество записей
- Распределение по годам
- Распределение по производителям

## БЫСТРЫЙ СТАРТ

### 1. Запуск приложения

```bash
# Перейдите в директорию проекта
cd 1_arshin_search

# Через скрипт запуска (рекомендуется)
# Linux:
./run.sh
# Windows:
run.bat

# Или вручную:
# Активация виртуального окружения
# Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Запуск приложения
python arshin_app.py
```

### 2. Первый поиск

1. Откройте вкладку **"🔍 Поиск"**
2. Введите заводской номер (например: `11553781`)
3. Выберите годы (по умолчанию все выбраны)
4. Нажмите **"▶ Найти"**
5. После завершения выберите действие:
   - **"💾 Сохранить в CSV"** — экспорт результатов
   - **"➕ Добавить в БД"** — сохранение в базу
   - **"✖"** — закрыть диалог

## ВКЛАДКА "🔍 ПОИСК"

### Назначение
Одиночный поиск по заводскому номеру прибора.

### Интерфейс

```
┌─────────────────────────────────────────────────────────┐
│  Зав. номер: [______________] ▶ Найти ⏹ Стоп ✖ Очистить│
│  ℹ️ Готов к поиску                                      │
│  Годы:                                                  │
│  ☑2010 ☑2011 ☑2012 ... ☑2025 ☑2026                     │
└─────────────────────────────────────────────────────────┘
```

### Элементы управления

| Элемент | Описание |
|---------|----------|
| **Зав. номер** | Поле ввода заводского номера прибора |
| **▶ Найти** | Запуск поиска (зелёная кнопка) |
| **⏹ Стоп** | Остановка поиска (красная кнопка) |
| **✖ Очистить** | Очистка результатов для нового запроса |
| **Годы** | Чекбоксы для выбора годов поиска (2010-2026) |

### Поиск

1. Введите заводской номер в поле **"Зав. номер"**
2. Выберите годы чекбоксами (по умолчанию все выбраны)
3. Нажмите **"▶ Найти"**
4. Ожидайте завершения поиска
5. В диалоге выберите действие:
   - **"💾 Сохранить в CSV"** — сохранить результаты в файл
   - **"➕ Добавить в БД"** — добавить записи в базу данных
   - **"✖"** — закрыть диалог, результаты останутся в таблице

### Остановка поиска

- Нажмите **"⏹ Стоп"** во время поиска
- Поиск остановится после завершения текущего запроса
- Найденные записи будут показаны в таблице

### Очистка

- Нажмите **"✖ Очистить"** для подготовки к новому поиску
- Поле ввода и таблица результатов будут очищены

### Работа с результатами

**Выделение строк:**
- **Одна строка:** Клик левой кнопкой мыши
- **Несколько:** Ctrl+Click или Shift+Click

**Действия:**
- **"💾 Сохранить CSV"** — сохранить все результаты в CSV
- **"➕ В БД"** — добавить все результаты в базу данных
- **"🗑 Удалить выбранные"** — удалить выделенные строки

## ВКЛАДКА "📦 ПАКЕТНАЯ"

### Назначение
Пакетный поиск по списку приборов из Excel файла.

### Подготовка файла

**Требуемые колонки:**
- **Серийный номер** (обязательно) — для поиска
- **Id_ПУ** (рекомендуется) — идентификатор прибора
- **Модель** (рекомендуется) — наименование модели
- **Тип ПУ** (рекомендуется) — тип прибора
- **Номер договора** (опционально) — для экспорта
- **Код ЭДО** (опционально) — для экспорта
- **Балансовая принадлежность** (опционально)
- **Эксплуатационная ответственность** (опционально)
- **МПИ** (опционально) — межповерочный интервал

**Шаблон:**
- Нажмите кнопку **"📄"** для создания шаблона Excel

### Поиск

1. Нажмите **"📂"** и выберите Excel файл
2. Проверьте предпросмотр в таблице
3. Выберите годы чекбоксами
4. Нажмите **"▶ Запуск"**
5. Ожидайте завершения поиска
6. Результаты автоматически добавятся в базу и откроются во вкладке **"📋 Результаты"**

### Остановка поиска

- Нажмите **"⏹ Стоп"** во время поиска
- Поиск остановится после завершения текущего запроса

## ЧАСТЫЕ ВОПРОСЫ

### ❓ Почему не находятся записи?

**Возможные причины:**
1. Неверный заводской номер
2. Запись отсутствует в реестре ФГИС
3. Не выбран год поиска

**Решение:**
- Проверьте правильность ввода номера
- Попробуйте другие годы
- Проверьте логи в папке `logs/`

---

### ❓ Как добавить новые запросы?

**Способ 1:** Через вкладку **"🔧 Фильтры"**
1. Откройте вкладку
2. Нажмите **"➕ Добавить"**
3. Введите запрос, категорию, приоритет
4. Нажмите **"💾 Сохранить в файл"**

**Способ 2:** Прямое редактирование
1. Откройте `config/exact_queries.csv`
2. Добавьте новую строку
3. Сохраните файл
4. Перезапустите приложение

---

### ❓ Как очистить базу данных?

1. Откройте вкладку **"📋 Результаты"**
2. Нажмите **"🗑 БД"**
3. Подтвердите действие

⚠️ **Внимание:** Это действие нельзя отменить!

---

### ❓ Что делать если ошибка при запуске?

**Используйте скрипт запуска (рекомендуется):**
```bash
# Linux:
./run.sh

# Windows:
run.bat
```

Скрипт автоматически:
- ✅ Проверит виртуальное окружение
- ✅ Проверит и установит зависимости
- ✅ Запустит приложение

**Если ошибка сохраняется:**

1. Проверьте наличие виртуального окружения:
   ```bash
   ls venv/
   ```

2. Проверьте зависимости:
   ```bash
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Проверьте логи:
   ```bash
   ls logs/
   ```

4. Проверьте наличие tkinter (требуется для GUI):
   ```bash
   # Linux (Ubuntu/Debian):
   sudo apt-get install python3-tk
   
   # Проверка:
   python -c "import tkinter; print('OK')"
   ```
