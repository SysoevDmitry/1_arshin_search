# 3 ОПИСАНИЕ ВНЕШНЕГО ПУБЛИЧНОГО ИНТЕРФЕЙСА


Компонент «Внешний публичный интерфейс» доступен по адресу:  
`https://fgis.gost.ru/fundmetrology/eapi/`

Информационное обеспечение компонента «Внешний публичный интерфейс» включает формат запросов к компоненту со стороны внешних информационных систем и формат JSON-структуры, возвращаемой в ответ на запрос. Описания форматов представлены в настоящем разделе по каждому информационному объекту.

---

## 3.1.1 Реестр утвержденных типов СИ

### 3.1.1.1 ПОЛУЧЕНИЕ СПИСКА ЭЛЕМЕНТОВ РЕЕСТРА

#### 3.1.1.1.1 Запрос

| Параметр      | Значение                                                                 |
|---------------|--------------------------------------------------------------------------|
| HTTP-метод    | `GET`                                                                    |
| URL           | `/mit`                                                                   |
| Параметры     | `search` – подстрока поиска (по умолчанию `*`)<br>`sort` – атрибут и порядок сортировки (не используется по умолчанию)<br>`start` – порядковый номер начальной записи (по умолчанию `0`)<br>`rows` – количество элементов на страницу (по умолчанию `10`, максимум `100`) |
| Доп. информация | —                                                                      |

##### 3.1.1.1.1.1 ПАРАМЕТРЫ

**`search`**  
Поиск производится по атрибутам:
- номер в реестре;
- наименование типа СИ;
- обозначение типа СИ.

Символ `*` используется как маска для любых символов:
- Для поиска записей, начинающихся с заданной строки: `search=строка_поиска*`
- Для поиска подстроки: `search=*строка_поиска*`
- Для поиска по нескольким значениям (логическое И): `search=строка1%20строка2%20строка3`

**`sort`**  
Задается в формате: `{атрибут}+{порядок}`  
Доступные значения порядка: `asc`, `desc`  
Список атрибутов для сортировки см. в п. 3.1.1.1.2.1.

##### 3.1.1.1.1.2 ПРИМЕРЫ ВЫЗОВОВ

Получить все элементы, начиная с 5-го элемента, 20 элементов на страницу:

```http
GET /eapi/mit?start=5&rows=20 HTTP/1.1
Host: fgis.gost.ru
````

## 3.1.7 Реестр сведений о результатах поверки СИ

#### 3.1.7.1.1 Запрос

|Параметр|Значение|
|---|---|
|HTTP-метод|`GET`|
|URL|`/vri`|
|Параметры|`year` – год (по умолчанию текущий)  <br>`search` – подстрока поиска (по умолчанию `*`)  <br>`sort` – атрибут и порядок сортировки (не используется по умолчанию)  <br>`start` – порядковый номер начальной записи (по умолчанию `0`)  <br>`rows` – количество элементов на страницу (по умолчанию `10`, максимум `100`)|
|Доп. информация|—|

##### 3.1.7.1.1.1 ПАРАМЕТРЫ

**`search`**  
Поиск производится по атрибутам:

- наименование организации-поверителя;
- регистрационный номер типа СИ;
- наименование типа СИ;
- обозначение типа СИ;
- модификация СИ;
- заводской / серийный номер СИ / буквенно-цифровое обозначение;
- номер свидетельства / извещения / выписки.

Символ `*` используется как маска:

- Для поиска записей, начинающихся с заданной строки: `search=строка_поиска*`
- Для поиска подстроки: `search=*строка_поиска*`
- Для поиска по нескольким значениям: `search=строка1%20строка2%20строка3`

**`sort`**  
Задается в формате: `{атрибут}+{порядок}`  
Доступные значения порядка: `asc`, `desc`  
Список атрибутов для сортировки см. в п. 3.1.7.1.2.1.

##### 3.1.7.1.1.2 ПРИМЕРЫ ВЫЗОВОВ

Получить все элементы за 2020 год, начиная с 5-го элемента, 20 элементов на страницу:

```http
GET /eapi/vri?year=2020&start=5&rows=20 HTTP/1.1
Host: fgis.gost.ru
```
Получить все элементы за 2020 год, включающие подстроку «цсм», отсортировать по колонке «номер» в обратном порядке:

```http
GET /eapi/vri?year=2020&search=*цсм*&sort=number+desc HTTP/1.1
Host: fgis.gost.ru
```
