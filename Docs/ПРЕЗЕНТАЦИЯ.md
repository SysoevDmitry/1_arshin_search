## 🎯 О ПРОЕКТЕ

**ФГИС АРШИН** — приложение для работы с федеральной государственной информационной системой «Аршин»

### Назначение
- 🔍 Поиск по реестру поверок средств измерений (электросчётчики)
- 📦 Пакетная обработка запросов из Excel
- 📊 Экспорт результатов с полной служебной информацией
- 🚀 Консольная версия для удалённых серверов и автоматизации

### Платформы
| Linux | Windows |
|-------|---------|
| ✅ GUI (Tkinter) | ✅ GUI (Tkinter) |
| ✅ Console | ✅ Console |
| ✅ AppImage | ✅ Portable EXE |

### Что нового в v3.0
- **Атрибутивный поиск** (`mi_number=`, `mit_number=`) согласно спецификации API v.2.2
- **Динамический rate limiting** — адаптивная частота запросов (0.1–0.5с) с реакцией на HTTP 429
- **Сохранение ведущих нулей** в серийных номерах (`023241147596`)
- **№ наклейки** (`sticker_num`) в данных и экспорте
- **Динамические колонки** (`extra_fields`) — любые поля из Excel
- **Год выпуска** прибора — поиск от года выпуска (консольная версия)
- Две версии (v1.2 + v2.1) объединены в одну

## GUI: ВКЛАДКА «ПОИСК»

### Одиночный поиск по заводскому номеру

| Элемент | Описание |
|---------|----------|
| **Зав. номер** | Поле ввода заводского номера прибора |
| **▶ Найти** | Запуск атрибутивного поиска (`mi_number=`) |
| **⏹ Стоп** | Остановка поиска |
| **✖ Очистить** | Очистка результатов |
| **Годы** | Выбор годов поиска (2010–2026) |

### Действия с результатами
- **💾 Сохранить CSV** — экспорт результатов
- **➕ В БД** — добавление записей в базу данных
- **🗑 Удалить выбранные** — удаление строк из таблицы

### Таблица результатов (12 колонок)

| Колонка | Описание |
|---------|----------|
| ID записи | Идентификатор VRI |
| № наклейки | Номер наклейки (`sticker_num`) |
| № в реестре | Номер в реестре ФГИС |
| Наименование СИ | Название средства измерения |
| Обозначение | Тип СИ |
| Модификация | Модификация прибора |
| Зав. номер | Заводской номер |
| Дата поверки | Дата проведения поверки |
| Действ. до | Действительна до |
| Пригоден | Пригодность |
| Поверитель | Организация-поверитель |
| № документа | Номер документа |

## GUI: ВКЛАДКА «ПАКЕТНАЯ»

### Пакетный поиск из Excel файла

**Поддерживаемые колонки:**
| Колонка | Обязательно | Описание |
|---------|-------------|----------|
| Заводской номер | ✅ | Серийный номер для поиска |
| Id_ПУ | ❌ | Идентификатор точки учёта |
| Наименование | ❌ | Тип прибора |
| Номер в реестре | ❌ | Номер в реестре СИ |
| Год выпуска | ❌ | Год выпуска прибора |
| Номер договора | ❌ | Договор с поставщиком |
| Код ЭДО | ❌ | Код электронного документооборота |
| МПИ | ❌ | Межповерочный интервал |
| Балансовая принадлежность | ❌ | Владелец |
| Эксплуатационная ответственность | ❌ | Ответственный |

**Алгоритм:** автоматическое определение колонок по заголовкам (наилучшее совпадение). Ведущие нули в серийных номерах сохраняются.

### Статистика обработки
- **Обработано** — количество строк
- **Найдено** — количество найденных записей
- **Отфильтровано** — после фильтрации (не электросчётчики)

## КОНСОЛЬНАЯ ВЕРСИЯ (Konsol_Excel)

### Возможности v6.2

| Характеристика | Описание |
|----------------|----------|
| Интерфейс | Терминал (SSH/tmux/screen) |
| Параллелизм | asyncio, до 10 одновременных запросов |
| Поиск | Атрибутивный (`mi_number=`) + retry |
| Excel | Автоопределение колонок, ведущие нули |
| Год выпуска | Поиск от года выпуска до конца диапазона |
| БД | 14 полей уникальности |
| Экспорт | Автосохранение в `exports/`, умные имена |
| Логи | `Logs/arshin_excel_*.log` |
| Автоматизация | cron, tmux, screen |

### Запуск

```bash
cd Konsol_Excel

# Поиск по диапазону
./run.sh -f Запрос_100.xlsx -y 2015-2026 -o результат.csv

# Статистика
./run.sh --stats

# Шаблон
./run.sh --template шаблон.xlsx
```

### Фоновая работа

```bash
# tmux
tmux new -s arshin
./run.sh -f запрос.xlsx -y 2015-2026 -o результат.csv
# Ctrl+B, D — отключиться
tmux attach -t arshin  # вернуться

# screen
screen -S arshin
./run.sh -f запрос.xlsx -y 2015-2026 -o результат.csv
# Ctrl+A, D — отключиться
screen -r arshin  # вернуться
```
