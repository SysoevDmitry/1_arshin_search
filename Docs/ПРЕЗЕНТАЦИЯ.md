## 🎯 О ПРОЕКТЕ

**ФГИС АРШИН** — приложение для работы с федеральной государственной информационной системой "Аршин"

### Назначение
- 🔍 Поиск по реестру поверок средств измерений
- 📦 Пакетная обработка запросов из Excel
- 📊 Экспорт результатов с полной служебной информацией
- 🚀 Консольная версия для удалённых серверов

### Платформы
| Linux | Windows |
|-------|---------|
| ✅ GUI (Tkinter) | ✅ GUI (Tkinter) |
| ✅ Console | ✅ Console |
| ✅ AppImage | ✅ Portable EXE |

## 📦 ВКЛАДКА "ПАКЕТНАЯ"

### Пакетный поиск из Excel файла

![Вкладка Пакетная](Картинки/пакетная.png)

### Подготовка файла

**Требуемые колонки:**
- **Серийный номер** (обязательно) — для поиска
- **Id_ПУ** (рекомендуется) — идентификатор прибора
- **Модель** (рекомендуется) — наименование модели
- **Тип ПУ** (рекомендуется) — тип прибора
- **Номер договора** (опционально)
- **Код ЭДО** (опционально)
- **Балансовая принадлежность** (опционально)
- **Эксплуатационная ответственность** (опционально)
- **МПИ** (опционально) — межповерочный интервал

### Параметры

| Параметр | Описание |
|----------|----------|
| **Excel** | Путь к файлу с запросами |
| **Годы** | Выбор годов для поиска |
| **▶ Запуск** | Начало пакетной обработки |
| **⏹ Стоп** | Остановка обработки |

### Статистика обработки

- **Обработано** — количество обработанных строк
- **Найдено** — количество найденных записей
- **Отфильтровано** — количество после фильтрации

## 🔧 ВКЛАДКА "ФИЛЬТРЫ"

### Управление конфигурацией

![Вкладка Фильтры](Картинки/Фильтры.png)

### Точные запросы

**Файл:** `config/exact_queries.csv`

**Формат:**
```csv
# query,category,priority
Счетчик электрической энергии Меркурий 201,electric,high
Счетчик электрической энергии Нева 103,electric,high
```

**Категории:**
- `electric` — электроэнергия
- `gas` — газ
- `water` — вода
- `heat` — тепло
- `other` — прочее

**Приоритеты:**
- `high` — высокий
- `medium` — средний
- `low` — низкий

### Производители

**Файл:** `config/manufacturers.csv`

**Формат:**
```csv
# keyword,manufacturer,category,priority
меркурий,Меркурий (Инкотекс),electric,high
нева,Нева,electric,high
энергомера,Энергомера,electric,high
```

### Кнопки управления

| Кнопка | Описание |
|--------|----------|
| **📂 Загрузить** | Загрузить из файла |
| **💾 Сохранить** | Сохранить в файл |
| **🗑 Очистить** | Очистить список |
| **➕ Добавить** | Добавить новый элемент |
| **🔄 Из файла** | Загрузить стандартный файл |

## 🚀 УСТАНОВКА И ЗАПУСК

### Быстрый старт (Linux)

```bash
# 1. Переход в директорию
cd /home/dmitry/Документы/АРШИН/Интерфейс/1_arshin_search

# 2. Активация виртуального окружения
source venv/bin/activate

# 3. Установка зависимостей (если нужно)
pip install -r requirements.txt

# 4. Запуск GUI версии
python arshin_app.py
```

### Консольная версия

```bash
# Пакетный поиск
python arshin_app_konsol.py -f файл.xlsx -y 2020,2021,2022

# С экспортом в CSV
python arshin_app_konsol.py -f запросы.xlsx -y 2020-2025 -o результат.csv

# Просмотр статистики
python arshin_app_konsol.py --stats

# Очистка БД
python arshin_app_konsol.py --clear

# Помощь
python arshin_app_konsol.py --help
```
